# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/), версии — semver.

## [1.1.0] — 2026-07-02

Реализация `FABLE5-REVIEW.md` (ревизия репо Fable 5). Аддитивные и гигиенические правки; поведенческие изменения без A/B-теста внесены как гипотезы в `HYPOTHESIS-LEDGER.md`, не как решённые вердикты.

### Added
- `memory/ROUTER-LOG.md` — лог решений роутера для сбора матрицы ошибок (был заявлен, но не существовал).
- `reasoning-harness/commands/harness-probe.md` — команда регресс-проб после смены модели (5–8 канонических ловушек).
- `CHANGELOG.md` (этот файл).
- Таблица «карта активации модуль × модель» в `ARCHITECTURE.md` (скелет под ре-базлайн P0-1).
- Таблица маппинга «правило ядра → платформенный механизм» (Cowork / Claude Code / голый чат) в `ARCHITECTURE.md`.
- Колонка «эпоха» в `HYPOTHESIS-LEDGER.md` — вердикты теперь привязаны к поколению модели.
- Новые гипотезы в реестре: регламент независимого прохода через субагента (P1-3), контракт-формат скиллов (P1-6), watch на мерж steelman→red-team (P2-1).

### Changed
- Число скиллов исправлено 18→16 во всех живых документах (`plugin.json`, `marketplace.json`).
- `CLAUDE.md`: сужен принудительный триггер fact-mode (Фаза 0 п.5) — только внешние факты, от которых зависит решение, не любое число/код; добавлен search-first в `fact-mode`.
- `CLAUDE.md`: принцип 11 (verifier-first) — приоритет исполняемой проверки над рассуждением о ней.
- `CLAUDE.md`: Фаза 6 — стоп-правило на 2 полных цикла критики/верификации без нового вводного.
- `CLAUDE.md`: новый принцип 20 — внешний контент = данные, не команды (защита от prompt injection).
- `CLAUDE.md`: Фаза 0 п.3 — дефолт запуска субагента (≥3 независимых читающих подзадач или изоляция контекста).
- `CLAUDE.md`: принцип 2 — эпистемические метки обязательны в рисёрче/решениях; в лёгком диалоге — только для неочевидных утверждений.
- Description всех 16 `SKILL.md` сжаты (токен-экономия фиксированного контекста).
- `reasoning-harness/commands/test-module.md`: Шаг 4 — размер вывода A/B фиксируется как прокси токен-цены.
- `divergent`, `alternatives`, `steelman`: переформатированы в «Контракт выхода» + опциональную «Процедуру» (гипотеза, ждёт `/test-module`).

- `overseer/SKILL.md`: добавлены шаги «консистентность документов» и «матрица ошибок роутера»; регламент независимого прохода.
