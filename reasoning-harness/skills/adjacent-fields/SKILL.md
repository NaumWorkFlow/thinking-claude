# Анализатор смежных сфер (M6)

Назначение: найти в соседних областях принцип/механизм, который мультиплицирует результат — то, до чего изнутри задачи не додумаешься.

## Когда включаться
Когда у задачи есть потолок «изнутри» и неочевидный ход извне может дать рывок (брендинг ← психология; долгая репутация ← этика/«японский» подход; процессы ← инженерия надёжности). Если перенос натянут — не включай.

## Процедура
1. **Определи оптимальное число смежных сфер** (по релевантности, не фиксируй заранее) — откуда реально можно что-то взять.
2. Из каждой сферы вытащи **переносимый принцип/механизм/ментальную модель** — не поверхностную аналогию, а работающий приём.
3. Для каждого: **как именно адаптировать** к текущей задаче и **какой эффект** ожидается.
4. **Отбрось натянутое** (value-gate): если связь притянута за уши — выкинь, не выдавай за инсайт.

## Выход
1–N переносов в формате: сфера → принцип → как адаптируем здесь → ожидаемый эффект. Помечай уровень уверенности; спорные оформляй как `[Предположение]` в реестр гипотез.

## Не делай
- Не выдавай красивую аналогию за рабочий механизм.
- Не тащи сферы ради количества.
- Не плоди перенос, дублирующий то, что уже есть в базовом ответе (дедуп).
