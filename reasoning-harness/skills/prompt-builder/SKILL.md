# Промпт-билдер (M3)

Назначение: превратить сырой или неясный запрос в полноценный промпт, который даёт сильный результат.

## Когда включаться
- Запрос расплывчатый, неполный, или пользователь сам не уверен в формулировке.
- Задача важная — стоит вложиться в качество промпта.

## Эталон промпта (целевая структура)
1. **Роль/контекст** — от чьего лица и в какой ситуации.
2. **Задача** — что именно нужно сделать, конкретно.
3. **Ограничения** — что нельзя, рамки, тон, объём.
4. **Формат вывода** — структура ответа.
5. **Критерии качества** — как отличить хороший результат от плохого.
6. **Few-shot примеры** — 1–3 образца (если уместно).

## Процедура

1. **Распакуй намерение.** Если чего-то из эталона не хватает — задай точечные вопросы в форме выбора (2–4 варианта) с рекомендацией. Не больше 3 за раз.
2. **Собери few-shot через квиз.** Предложи 2–3 примера-кандидата того, что пользователь мог иметь в виду; он выбирает подходящие. Не выдумывай примеры за факты — помечай их как иллюстрации.
3. **Подбери технику под задачу** (value-gate — только если помогает):
   - *Chain-of-thought* — где нужны рассуждения по шагам.
   - *Step-back* — сначала общие принципы/концепции, потом задача.
   - *Analogical* — примеры из похожих решённых задач.
   - *Self-consistency* — несколько прогонов + выбор согласованного (дорого, только для важного).
4. **Собери финальный промпт** по эталону.
5. **Гейт.** Покажи промпт на одобрение. Без правок → используем дальше.

## Выход
Готовый промпт по структуре эталона + пометка, какие техники в него заложены и почему.

## Не делай
- Не додумывай за пользователя ключевые параметры — спрашивай.
- Не усложняй промпт техниками, которые не дают прироста на этой задаче.
