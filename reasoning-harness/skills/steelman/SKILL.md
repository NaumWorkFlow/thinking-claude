# Стилман (M16)

Назначение: сначала собрать идею в её сильнейшем виде, и только потом критиковать. Так критика бьёт по сути, а не по слабой подаче.

## Процедура
1. Возьми идею/позицию и сформулируй её **сильнейшую** версию — как её защищал бы самый умный и честный сторонник.
2. Добавь лучшие аргументы и условия, при которых она верна (даже если ты с ней не согласен).
3. Передай этот усиленный вариант дальше — в `red-team` для критики или пользователю для честной оценки.

## Когда особенно нужен
Перед критикой; при разборе позиции, с которой не согласен; когда первая реакция — «это очевидно плохо».

## Выход
Сильнейшая версия идеи (1 абзац) + условия, при которых она работает.

## Не делай
- Не подменяй стилман соломенным чучелом (не ослабляй идею втихую).
- Не застревай в защите — это шаг перед критикой, не вместо неё.
- **Не применяй стилман к coding/implementation-задачам** (фикс гейта): там он только раздувает ответ.
