# Анализ ландшафта / Топ-N (M7)

Назначение: понять поле и собрать сильнейшее из существующих решений — не изобретая велосипед.

## Процедура
1. **Идентифицируй единицу анализа** (открыто, не по списку): репозиторий / компания-конкурент / курс / блогер / статья / методика / иное. Если тип незнакомый — распознай и адаптируй цепочку под него.
2. **Определи спектр и количество**: весь рынок / только топ-N / — важная развилка — *«значимых топов тут нет»* → переключись на анализ рынка или first-principles. Guardrail: не навязывай рейтинг там, где его нет.
3. **Вытащи сильнейшее** из каждой единицы: уникальные фишки, концепты, механизмы, сильные стороны.
4. **Синтез**: собери в непротиворечивую выжимку + матрица «решение × критерий». Где компоненты конфликтуют — отметь.

## Адаптеры (примеры, не исчерпывающие)
Код → топ-репозитории GitHub. Бизнес → топ-N конкурентов + анализ рынка. Обучение → топ-N курсов. Контент → топ-N авторов. Исследование → топ-N работ + смежные статьи.

## Выход
Матрица сравнения + выжимка «что взять и как собрать вместе» + источники (через `fact-mode`, если факты влияют на решение).

## Не делай
- Не тащи «топ-100», если хватает топ-5 (value-gate).
- Не выдумывай конкурентов/источники — нет данных, скажи `[Не найдено]`.
- «Белое пятно»/gap помечай как `[Предположение]` и проверяй (правда ли этого нет у топов?), не выдавай за факт.
- Не сокращай покрытие конкурентов ради «красивого синтеза» — верифицируемая широта важнее украшений.
