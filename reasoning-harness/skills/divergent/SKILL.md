# Дивергентный режим (M11)

Назначение: симулировать «озарение» через управляемое расхождение и последующее схождение — а не один «умный» проход.

## Процедура
1. **Фаза расхождения.** Сгенерируй много (10–15) разных идей широко, включая нестандартные, без самоцензуры. Приёмы: случайный стимул, инверсия задачи («как сделать наоборот / как гарантированно провалить»), форсированные связи, аналогии из далёких сфер.
2. **Фаза схождения.** Отбери 2–3 лучших по критериям: ценность × осуществимость. Остальное отбрось.
3. По отобранным дай короткое обоснование, чем они сильны.

## Когда нужен
Брейнсторм, нейминг, концепции, выход из тупика, поиск неочевидного хода. Не для рутинных/расчётных задач (value-gate).

## Выход
2–3 отобранные идеи (из широкой генерации) с обоснованием. Сырой длинный список не вываливай — покажи по запросу.

## Не делай
- Не путай объём с ценностью: без фазы отбора это шум.
- Спорные идеи помечай `[Предположение]`, не выдавай за проверенные.
