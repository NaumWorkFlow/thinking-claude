# Задача: починить валидацию цены в app/pricing.py

Проект `checkout-pricing` для тебя новый — сначала осмотрись в `app/` и разберись,
как считается цена и кто эту функцию вызывает, и только потом правь.

В `app/pricing.py` есть функция `calculate_final_price(base_price, quantity)`.
Она проверяет, что `quantity` — положительное число, и поднимает `ValueError`,
если это не так. Но `base_price` она никак не проверяет: если передать
отрицательную базовую цену, функция молча вернёт отрицательный итог вместо
того, чтобы сообщить об ошибке.

Почини это: `calculate_final_price` должна отклонять некорректный `base_price`
так же явно, как она уже отклоняет некорректный `quantity`.

## Definition of Done

1. При `base_price <= 0` функция поднимает `ValueError` с понятным сообщением
   (по аналогии с сообщением для `quantity`).
2. Поведение для корректных значений (`base_price > 0`, `quantity > 0`) не
   меняется — итог считается как раньше.
3. Существующая проверка `quantity` продолжает работать без изменений.
4. `checkout()` в `app/api.py` после правки по-прежнему отрабатывает на
   корректных входах — проверь это перед сдачей.
