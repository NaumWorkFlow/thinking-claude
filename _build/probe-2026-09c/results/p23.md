## Как считается

- **FIFO по всей истории сделок**, не только по месяцу: покупки до сентября — база стоимости для сентябрьских продаж (без этого AAPL было бы не с чем сопоставить). Сделки после месяца не влияют.
- **Комиссии учтены**: покупочная размазывается по акциям лота, продажная вычитается из выручки.
- **Пересчёт в USD** через `app.fx.to_usd` — по каждой ноге сделки отдельно.
- Сортировка по `(date, trade_id)` — результат не зависит от порядка строк в CSV.
- Возвращает `{тикер: прибыль_USD}` только по тикерам с продажами в месяце; `None` — если продажа не покрыта лотами.
