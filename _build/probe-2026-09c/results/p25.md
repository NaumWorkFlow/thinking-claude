## Два важных момента

**1. Курс MDL в `app/fx.py` был перевёрнут — исправил.** По комментарию модуля `RATES` хранит «сколько USD стоит 1 единица валюты» (USD 1.0, EUR 1.08 — верно), а для MDL стояло `17.8`, то есть «1 лей = 17.8 доллара». На самом деле 17.8 — это леев за доллар. С таким курсом прибыль по MAIB в отчёте была бы **$13 216** вместо **$41.71**. Поменял на `1 / 17.8` (исходное число оставил видимым) и добавил тест `test_mdl_is_fraction_of_dollar`. Это правка вне `report.py` — если курс был задан так намеренно, откатить одну строку легко, но тогда отчёт по MAIB будет ложным.

**2. TSLA продана без покупки в выгрузке — прибыль не посчитать, и я её не выдумываю.** Сделка 5 (2026-09-12, SELL 3 TSLA @ 250) — единственная сделка по TSLA в `data/trades.csv`; выгрузка начинается с 2026-08-20, позиция явно открыта раньше. Наивный расчёт дал бы «+$749 прибыли» с нулевой базой — это неправда. `realized_pnl` возвращает для такого тикера `None`, в таблице печатается `n/a` со сноской, итог считается без него и помечен звёздочкой. Чтобы TSLA попала в отчёт, нужна покупка в выгрузке (или строка-остаток на начало периода).

## Что реализовано

`app/report.py`:
- `realized_pnl(trades, year, month)` → `{тикер: прибыль в USD}` по продажам за месяц. Лоты сопоставляются **FIFO в хронологическом порядке по всей истории** (не по порядку строк в файле): покупки прошлых месяцев формируют базу, продажи прошлых месяцев её расходуют, покупка *после* продажи в том же месяце её не покрывает. Комиссии учтены: комиссия покупки размазана по единицам лота, комиссия продажи вычтена из выручки. Конвертация через `to_usd`. Если продажу нельзя полностью закрыть лотами — тикер → `None`.
- `python -m app.report 2026 9` — печатает таблицу и итог по `data/trades.csv` (путь по умолчанию привязан к корню проекта, есть `--trades`). Месяц вне 1..12 отклоняется.

Тесты: `tests/test_report.py` — 19 тестов (FIFO по лотам, частичная продажа, порядок дат vs порядок строк, фильтр месяца, расход лотов в прошлых месяцах, продажа без покупки / сверх остатка, конвертация валют, независимость тикеров, пустой месяц, неизвестный `side`, контрольные цифры по `data/trades.csv`, CLI). Плюс тест на MDL в `test_fx.py`. `python -m unittest discover` из корня: **23 теста, OK**. Ещё поправил строку в README (`report.py — пока пусто` уже неправда).
