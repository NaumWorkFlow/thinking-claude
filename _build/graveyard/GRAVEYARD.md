# Кладбище модулей

Модули, выведенные из системы по итогам двойной внешней оценки (релиз-вычитание, 2026-06-28). Хранятся для истории, в плагин НЕ входят.

- **prioritization (M17)** — дроп. Причина: чистое дублирование встроенного поведения (база сама строит «эффект÷усилия»); собственный вердикт был «условный, слабейший keep». Остаток (expected-value на конфликте метрик) перенесён в ядро.
- **benchmark (M9)** — дроп. Причина: база сама benchmark'ит на ~равном качестве без опасных провалов; маржинальные плюсы дублируют fact-mode. Остаток («назови+обоснуй конкретный проверяемый эталон») перенесён в ядро/fact-mode.

**Критерий выживания модуля теперь:** «переживёт ли он переход на более сильную модель?» Если база скоро будет делать это сама — кандидат в кладбище.
