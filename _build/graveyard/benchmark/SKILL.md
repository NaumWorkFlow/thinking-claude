# Эталон / планка (M9)

> ✅ **СТАТУС: KEEP+TWEAK** (ретест, 2026-06-28; пересмотр с drop). Ниша подтверждена: окупается при **нетривиальном подборе эталона** (Toptal vs Notion, LYT vs PARA — выбрал аналог точнее базы и дал task-specific апгрейды). **Триггер сужен** до неочевидного выбора эталона; на общеизвестных стандартах — деферить. Гейт на учебных задачах теперь молчит.

Назначение: не вариться в собственном соку — мерить работу против лучшего релевантного образца.

## Процедура
1. **Определи эталон под задачу** (не хардкодь «Кремниевую долину»): элитная команда / лидер индустрии / канонический стандарт или спека / топ-конкурент / эталонный пример / авторитет домена. Выбери то, что реально релевантно.
2. **Сравни** текущий уровень с эталоном по 2–4 значимым осям (не по всему подряд).
3. **Назови 1–2 конкретных апгрейда** — что именно подтянуть, чтобы приблизиться к планке. Конкретика, не «делай лучше».

## Выход
Эталон (с обоснованием выбора) + где разрыв + 1–2 точечных апгрейда.

## Не делай
- Не бери недостижимый/нерелевантный эталон ради красоты.
- Не превращай в общий разнос — только действенные апгрейды.
